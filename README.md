# Lumotion

Free all-in-one photo editor for iPhone and iPad (iOS 17+). SwiftUI, Core Image and Vision, all on device.
Crop and straighten, adjust with lens-style dials, 24 filters (17 made for Lumotion, 7 built on Apple photo effects), text, stickers, drawing, blur,
background removal, frames, collage, compress, resize, convert, watermark, ID photos and metadata cleanup.

Built with XcodeGen (`xcodegen generate`) and CI on GitHub Actions (macOS). See `.github/workflows`.
Production AdMob ids go into `Config/Release.xcconfig` before the first release.
